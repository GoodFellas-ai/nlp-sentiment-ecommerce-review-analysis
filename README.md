## 📌 Project Overview

This project is a complete **end-to-end Machine Learning application** that performs sentiment analysis on e-commerce customer reviews.

It integrates:
- Natural Language Processing (NLP)
- Transformer-based deep learning models
- Interactive Streamlit web application
- Exploratory Data Analysis (EDA)
- Cloud deployment using Hugging Face Spaces

The system predicts whether a customer review is **Positive or Negative** in real time.

---

## 🎯 Problem Statement

E-commerce platforms generate a large amount of customer feedback. Understanding customer sentiment is crucial for:
- Improving product quality
- Enhancing customer satisfaction
- Data-driven business decisions

This project automates sentiment classification from textual reviews.

## 📊 Dataset

**Women’s Clothing E-Commerce Reviews Dataset**

- Customer product reviews
- Ratings (1–5 scale)
- Product metadata (department, class, age, etc.)

Used for both sentiment analysis and exploratory data analysis.

---

## 🧠 Model Information

- Model: `distilbert-base-uncased-finetuned-sst-2-english`
- Type: Pre-trained Transformer (BERT family)
- Task: Binary Sentiment Classification
- Output: Positive / Negative + Confidence Score
